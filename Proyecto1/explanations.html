Elementos Semánticos

Los elementos semánticos proporcionan significado estructural al contenido, mejorando la accesibilidad y el SEO.

<article>

Representa contenido independiente y autocontenido que podría distribuirse por sí solo.

AtributoDescripciónOpcional
Ninguno específicoElemento de bloque-
Accesibilidad: Mejora la navegación para lectores de pantalla. Use junto con encabezados apropiados.

Referencia: HTML Living Standard

<aside>

Representa contenido tangencialmente relacionado con el contenido principal.

AtributoDescripciónOpcional
Ninguno específicoElemento de bloque-
Accesibilidad: Identifica contenido complementario. Los lectores de pantalla pueden ofrecer opciones para saltarlo.

Referencia: HTML Living Standard

<figure> y <figcaption>

<figure> representa contenido autocontenido, como ilustraciones. <figcaption> proporciona una leyenda.

AtributoDescripciónOpcional
Ninguno específicoElementos de bloque-
Accesibilidad: Asocia la imagen con su descripción. Use alt en img para texto alternativo.

Referencia: HTML Living Standard

Elementos de Texto

Elementos para estructurar y enfatizar texto.

<h1> - <h6>

Encabezados jerárquicos para estructurar el contenido.

AtributoDescripciónOpcional
Ninguno específicoElementos de bloque-
Accesibilidad: Esencial para navegación. Use jerarquía correcta (h1, luego h2, etc.). Evite saltos.

Referencia: HTML Living Standard

<p>

Representa un párrafo de texto.

AtributoDescripciónOpcional
Ninguno específicoElemento de bloque-
Accesibilidad: Proporciona pausas naturales en el contenido para lectores de pantalla.

<blockquote>

Representa una cita de otro fuente.

AtributoDescripciónOpcional
citeURL de la fuenteSí
Accesibilidad: Indica citas. Use cite para fuente si es relevante.

<cite>

Representa el título de una obra citada.

AtributoDescripciónOpcional
Ninguno específicoElemento en línea-

<mark>

Representa texto marcado o resaltado.

AtributoDescripciónOpcional
Ninguno específicoElemento en línea-
Accesibilidad: Use para resaltar información importante. Evite abuso que confunda.

<time>

Representa una fecha y/o hora específicas.

AtributoDescripciónOpcional
datetimeFecha/hora en formato válidoNo
Accesibilidad: Permite a los agentes de usuario representar fechas de manera significativa.

<abbr>

Representa una abreviatura o acrónimo.

AtributoDescripciónOpcional
titleExpansión completaSí
Accesibilidad: Proporciona expansión para lectores de pantalla. Siempre use title.

Multimedia

Elementos para contenido audiovisual.

<video>

Reproduce video.

AtributoDescripciónOpcional

loopRepite indefinidamenteSí

Accesibilidad: Proporcione transcripciones o subtítulos. Evite autoplay. Use <track> para subtítulos.

<audio>

Reproduce audio.

AtributoDescripciónOpcional

Accesibilidad: Proporcione transcripciones. Evite autoplay sin consentimiento del usuario.

Elementos Interactivos

Elementos que permiten interacción del usuario.

<details> y <summary>

<details> crea widget expandible/colapsable. <summary> es el encabezado visible.

AtributoDescripciónOpcional
openEstado inicial expandidoSí
Accesibilidad: Navegable por teclado. Lectores de pantalla anuncian estado.

<progress>

Representa progreso de una tarea.

AtributoDescripciónOpcional
valueValor actualSí
maxValor máximoSí
Accesibilidad: Anuncia progreso a lectores de pantalla. Use junto con aria-valuenow si necesario.

<meter>

Representa medida escalar dentro de rango conocido.

AtributoDescripciónOpcional
valueValor medidoNo
minValor mínimoSí
maxValor máximoSí
lowUmbral bajoSí
highUmbral altoSí
optimumValor óptimoSí

Gráficos

Elementos para gráficos vectoriales y rasterizados.

<canvas>

Área de dibujo para gráficos rasterizados usando JavaScript.

AtributoDescripciónOpcional
widthAncho en píxelesSí
heightAlto en píxelesSí
Accesibilidad: Proporcione texto alternativo. Use ARIA si es interactivo.

<svg>

Contenedor para gráficos vectoriales escalables.

AtributoDescripciónOpcional
widthAnchoSí
heightAltoSí
viewBoxÁrea visibleSí
Accesibilidad: Use title y desc para descripciones. Evite SVG puramente decorativo.

Elementos más especializados de HTML5.

AtributoDescripciónOpcional

Accesibilidad: Mejora autocompletado. Lectores de pantalla anuncian opciones disponibles.

<dialog>

AtributoDescripciónOpcional

<picture>

Contenedor para múltiples fuentes de imagen.

AtributoDescripciónOpcional
Ninguno específicoElemento de bloque-

<track>

Proporciona pistas de texto para media (subtítulos, etc.).

AtributoDescripciónOpcional
srcURL del archivo de pistaNo
kindTipo de pistaSí
srclangIdioma de la pistaSí
labelEtiqueta visibleSí
Accesibilidad: Esencial para contenido multimedia. Proporcione subtítulos para todos los videos.

Microdatos

Atributos para añadir metadatos semánticos: itemscope, itemtype, itemprop.

Accesibilidad: Mejora SEO y comprensión de contenido por máquinas. No afecta accesibilidad directa.

Atributos de Datos

Atributos data-* para almacenamiento de datos personalizados.

Accesibilidad: Use para mejorar funcionalidad. No reemplace atributos semánticos estándar.
